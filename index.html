What is JuggleJs?

JuggleJs counts football juggles from your camera — or from a video file. Put the phone down, keep the ball in frame, and watch the count climb.

Live session

  • Start / Resume — green control (or a hands-free pose).
  • Pause — yellow control, or Autopause after idle.
  • Stop / Reset — red control; clears the count.
  • Top bar shows timer, count, and menu.

Hands-free poses

Works only while you are not actively counting, so juggling keeps full FPS. Hold the pose about 1 second.

Arms up → Start / Resume

Raise both hands above your shoulders and hold. Same as tapping the green button.

Arms crossed → Stop / Reset

Cross your arms on your chest while paused. Same as tapping the red button.

Settings

  • Voice — volume for spoken counts and session words (OFF … MAX).
  • Say every — speak the count every N juggles (session words always speak).
  • Hands-free — enable pose controls.
  • Autopause — pause after ~5s without juggles.
  • Min bounce — how big a bounce must be to count (lower = more sensitive).
  • Trajectory / Ball / Stats — overlays for feedback and debugging.
  • From file + Debug step — test with a video; scrub and step frame by frame.

Install the app

Android (Chrome): tap Install when it appears (top-right), or use the browser menu → Install app. After the first online load it can work offline.

iPhone / iPad (Safari)

  2. Tap the Share button.
